## SQL conventions (read me before the first query)

Dialect: **SQLite**. No `ILIKE`, no `RETURNING`, no `::cast`, no `now()`.
`LIKE` is case-insensitive for ASCII; for explicit case-fold use
`LOWER(col) LIKE LOWER('…')`.
